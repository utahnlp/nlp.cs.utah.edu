# nlp.cs.utah.edu

**Step 1:** download Ruby ([https://www.ruby-lang.org/en/downloads/](https://www.ruby-lang.org/en/downloads/))

**Step 2:** make sure you have Bundler installed ([https://guides.rubygems.org/installation/](https://guides.rubygems.org/installation/))

```bash
bundle --version
```

**Step 3:** install website dependencies

```bash
bundle install
```

**step4:**  run locally:

```bash
bundle exec jekyll server -l
```
